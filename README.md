# Quizly

Open `index.html` in a browser to use the quiz locally.

## Publish free with GitHub Pages

1. Create a GitHub repository and upload the files in this folder.
2. In the repository, choose **Settings → Pages**.
3. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. GitHub will show the public website address shortly.

Edit the `questions` list in `script.js` to customize the quiz.
